# NextJob - Frontend

A modern job portal platform built with Next.js 15, React 19, and TypeScript.

## Features

- 🔍 Advanced job search and filtering
- 👤 User authentication and profile management
- 📊 Job dashboard and saved listings
- 🌓 Dark mode support
- 📱 Responsive design
- ⚡ Real-time job updates

## Tech Stack

- **Framework**: Next.js 15.5.9
- **UI Library**: Chakra UI v3
- **State Management**: Redux Toolkit
- **Styling**: Tailwind CSS v4
- **Forms**: React Hook Form
- **Language**: TypeScript

## Getting Started

### Installation

```bash
cd my-job-portal
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### Build

```bash
npm run build
npm start
```
